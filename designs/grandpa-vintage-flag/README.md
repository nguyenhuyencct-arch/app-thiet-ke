# Grandpa – Vintage American Flag (Men's T-Shirt)

An original print design for the **Kropsis Grandpa Vintage American Flag Men's T-Shirt**.

| File | Use |
|---|---|
| `design.svg` | Vector master. All text is converted to outlines, so no fonts are needed |
| `design-print.png` | Print file: 4500×5400 px (15×18 in @ 300 dpi) with a transparent background. Works for DTG, Printful, Printify, Merch on Demand and Etsy POD |
| `preview-navy.png`, `preview-charcoal.png`, `preview-black.png` | Previews on the dark shirt colors the design is made for |
| `generate.py`, `render.js` | Rebuild: `pip install fonttools brotli && python3 generate.py && node render.js` |

Palette: cream `#EFE6CF`, faded red `#B8443C`, navy `#2E3E5C`. The cream ink needs a dark shirt (navy, charcoal, black, military green); don't use it on white or light heather.
Fonts: Alfa Slab One and Oswald (SIL Open Font License, OK for commercial use).
